How it works — the automata theory

This system validates input using formal language concepts, specifically Deterministic Finite Automata (DFAs). Every keystroke triggers a complete DFA computation from the start state over the prefix string, mapping input segments directly to state transitions.

1. Username Automaton

Defines valid username strings: length 3 to 16 characters containing letters, digits, and underscores, beginning and ending with an alphanumeric character.

M₁ = (Q, Σ, δ, S, F)
Q = {S, A, B, C, ERR}
Σ = {a–z, A–Z, 0–9, _}
q₀ = S
F = {C}

Transition Table (δ):

State (q) Letter or Digit Underscore (_) Invalid / Overflow (>16 chars)
S (Start) A ERR ERR
A (Partially Valid) A (if len < 3) / C (if len ≥ 3) B ERR
B (Ended in Underscore) C B ERR
C (Accept State) C B ERR
ERR (Trap/Dead) ERR ERR ERR

2. Email Automaton

Tracks string structures mapping to local-part @ domain . tld. Implements a helper tracker to ensure the Top-Level Domain segment contains at least 2 characters.

M₂ = (Q, Σ, δ, S, F)
Q = {S, L, AT, D, DOT, T, ERR}
Σ = {a–z, A–Z, 0–9, ., _, %, +, -, @}
q₀ = S
F = {T} (subject to TLD segment length ≥ 2)

Transition Table (δ):

State (q) Local-Part Char At (@) Domain Char Dot (.) TLD Letter Invalid Char
S (Start) L (excl. .) ERR ERR ERR ERR ERR
L (Local Part) L AT ERR L ERR ERR
AT (@ Symbol) ERR ERR D (excl. .) ERR ERR ERR
D (Domain Part) ERR ERR D DOT ERR ERR
DOT (Dot Seen) ERR ERR ERR ERR T ERR
T (TLD Part) ERR ERR ERR DOT T ERR
ERR (Trap/Dead) ERR ERR ERR ERR ERR ERR

3. Password Automaton

A non-decreasing counting automaton representing the progressive satisfaction of 5 safety conditions. Once a condition is fulfilled, the counter increments, and the state transitions forward, never going back.

M₃ = (Q, Σ, δ, S0, F)
Q = {S0, S1, S2, S3, ACC}
Σ = {All ASCII Printable Characters}
q₀ = S0
F = {ACC} (representing exactly 5/5 rules satisfied)

Transition Table (δ):

State (q) New Condition Met No Condition State Change
S0 (0 Met) S1 (if 1 or 2 met) S0
S1 (1–2 Met) S2 (if 3 met) S1
S2 (3 Met) S3 (if 4 met) S2
S3 (4 Met) ACC (if 5 met) S3
ACC (All 5 Met) ACC ACC
